# Offline registry writer simulation

This module is an untrusted, single-writer test simulation. It only accepts a synthetic event minted in the current process, and only works in a specifically named private temporary directory. Its simulated terminal status and hashes are never production completion evidence or retention authorization. It is not connected to startup, a service, a listener, or an MCP tool. Initialization is only for a new disposable fixture; reopening a missing journal fails. A durable pending marker makes an interrupted update unknown and blocks further updates; no automated resolution is provided.

The SHA-256 checksums and event hashes are integrity mocks without secrets, not authentication. A malicious process running as the same UID can alter, replace, or remove the journal and marker, recompute hashes, or create a new fixture. A missing marker is indistinguishable from one removed by that process; the rollback test demonstrates this limitation. There is no rollback resistance against such a process, concurrent writers are unsupported, and pathname checks remain subject to TOCTOU races. Bounded reads check descriptor identity, ownership, mode, link count, size and timestamps before and after reading, but cannot establish same-UID trust. Atomic rename and fsync provide only the filesystem's actual guarantees, not a claim about hardware power-loss behavior. Fault tests inject both exceptions and SIGKILL into a paused disposable child at named steps; they do not simulate power loss. Native macOS peer credentials are not available in this simulation. Atomic OS-level conditional unlink by inode and digest is unavailable; the deletion simulation always rejects, including for symlinks. No production deletion is implemented.
